# 🧮 CALCLAB — Scientific Calculator Web App

⚡ Fast • 🎯 Accurate • 🧠 Smart  

A modern **Scientific Calculator** built with **HTML, CSS, and Vanilla JavaScript**, featuring advanced math, matrix operations, and probability calculations — all in your browser.

</div>

---

## ✨ Features

### 🧾 Core Calculator
- Basic arithmetic operations
- Decimal & negative numbers
- Clear & delete buttons

### 🔬 Scientific Mode
- Trigonometry (sin, cos, tan)
- Logarithm & natural log
- Square root & powers

### 🧩 Matrix Calculator
- Add, subtract, multiply matrices

### 🎲 Probability Tools
- Factorials
- Permutations
- Combinations


---

## 🛠 Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla)  
- math.js CDN
